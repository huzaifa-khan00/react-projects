# React Router Basics

Practice project for learning client-side routing with React Router.

## What this covers
- Setting up routes with `react-router`
- Building a navigation bar with links between pages
- Passing and displaying dynamic data (Users list, User card)
- Basic multi-page structure: Home, Users, Contact

## Run locally
```bash
npm install
npm run dev
```

## Notes
- Requires Node.js 22+
